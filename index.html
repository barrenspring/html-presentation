化繁为简之二：模板重构与人才赋能

⚡ 项目挑战 (以核心主项目 DNE 为例)：
主项目 DNE 包含 80+ 张复杂的借款底稿，且需要严格包含 IFRS 和 PRC 的 AFS（财务报表）披露内容。由于上年底稿模板及公式较为混乱，出错率极高，面临交付紧、任务重的重度压力。
🚀 破局思维与落地动作

拒绝纯粹机械地按部就班下发任务。主导并推行了"消化 → 重构 → 人才赋能"的完整闭环管理模式：

1. 统一标准化
重构整体底稿基础模板
2. 自动化取数
合理搭建公式自动完成匹配
3. 易错点梳理
提前固化并标注高频雷区
4. 手把手带教
带教Staff/Intern快速上手
💎 实际价值产出
  • 从源头彻底规避了后期由于理解偏差造成的大规模返工风险。
  • 显著提升了项目的综合交付效率与底稿合规质量。
  • 成功驱动组内 Staff 从简单的"机械填数工"向"具备业务研判思维的审计人"成功转型。

化繁为简之三：技术赋能与效率突破 (Python + AI)

💻 技术背景与痛点

面对超百万行级的海量序时账（Journal Entries），传统的 Excel 处理极易遭遇严重的算力瓶颈，导致软件频繁出现卡顿与崩溃。

import pandas as pd
result = pd.merge(balances, activity, on=['大类', '货币'], how='outer')
# 引入AI辅助编写的Python自动化清洗脚本
⚙️ 引入工具与硬核产出

技术手段：引入由 AI 辅助编写的高效 Python 自动化脚本，实现了针对数据清洗、规则筛选、多币种分类及汇总计算的全流程自动化。

核心价值：产出的清洗数据能够直接用于后续底稿的快速填制，将原本需要消耗数天人力的工作，完美缩短到仅需数小时即可交付。

研发：协同开发与标准落地

  • SOP编制：作为主力核心成员联合编制了 Sales TOD 的标准 SOP 及关键性指引文档，并全方位协助团队完成了 E1/E2 层级的 SOP 迭代与优化。
  • Pilot项目：深度且全程参与了 4 个具有代表性的 Pilot 服务试点项目，实时提炼并总结执行中的痛点与难点，针对性提出解决对策以不断修正 SOP 的可落地性。

Kaizen：持续改善与精益质量管理

  • 底稿易错点质控前置：深度加入并推进了 Kaizen 质检优化项目。通过全面复盘 FY26 的高频易错问题，开展深入的根因分析（RCA）。
  • 愿景实现：从"检测质量"向"制造质量"演进。推动底稿管理工作成功实现从遭遇问题后"事后救火"，向在初期即进行"预防管理"的职能大升级。从源头最大化降低审计项目的返工人力与实质性审计风险。

🌟 开启新征程：FY27 未来展望

1. 精益深化 · 质控前置
继续稳步推进底稿易错点的质量管理前置 Kaizen 项目，固化过往优秀成果，并持续追踪改善曲线。
2. 深化落地 · 拓新研发
进一步大面积扩大已上线的新底稿程序服务的承接范围与规模，并深度参与更多全新非标底稿的研发。
3. 带强队伍 · 做大交付
逐步向管理更高规模的并行多项目多团队矩阵进阶。在资源合理配置的同时深化 AI 技术的集成，突破交付极限。
